## Superteam Earn — Panta API Side Track

- **Project Name:** Sonar for Panta
- **Project Description:** Sonar for Panta is an intelligence and execution layer for Panta prediction markets on Solana. It scans every market the Panta API exposes, scores each one from its own trade tape (flow imbalance, 24h momentum, whale prints, wallet concentration, velocity), records the price history Panta doesn't expose, and prices every question against Polymarket and Kalshi to surface mispricings. From the same screen users buy YES/NO non-custodially through Panta's quote → build → sign → submit flow, claim winnings, and create new markets from a headline with Claude drafting the resolution rule. An autonomous agent paper-trades every medium-or-better call and settles against Panta's resolutions, publishing a live track record alongside a backtest over resolved Panta markets. It uses 14 Panta endpoints (catalog, detail, trades, positions, primary buy quote/build/submit/verify, create quote/build/register, claim build, trade report, account metrics) and ships with a 12-item API feedback report. Built by the team behind Sonar (sonar.nodalytics.xyz), a live signal engine on Kalshi/Polymarket with 672 resolved signals at a 57.7% 30-day win rate.
